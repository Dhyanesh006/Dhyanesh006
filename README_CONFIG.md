# README Config

## Variables

| Variable | Description |
| --- | --- |
| `{{USERNAME}}` | Your GitHub username. Used everywhere your profile handle is referenced (stats, workflows, badges, links). |
| `{{EMAIL}}` | Your contact email address. Displayed in the connect/footer section and used for `mailto:` links. |
| `{{LINKEDIN}}` | Your LinkedIn profile URL. Links your profile to your LinkedIn account in the connect section. |
| `{{PORTFOLIO}}` | The URL of your personal portfolio or website. Referenced in the about/connect sections. |
| `{{TWITTER}}` | Your Twitter (X) handle or profile URL. Links your profile to your Twitter account in the connect section. |
| `{{LEETCODE}}` | Your LeetCode username. Used to display LeetCode stats/badges. |
| `{{CODEFORCES}}` | Your Codeforces handle. Used to display Codeforces rating/stats. |
| `{{DEVTO}}` | Your DEV Community username. Used to display your DEV articles/stats. |
